<span style="background-color:rgba(242, 86, 29, 0.3)">注意：智能上传仅在 DefectDojo Pro 中提供。</span>

智能上传是一种专门的导入器，用于摄取来自**基础设施扫描工具**的报告，包括：

* Nexpose
* NMap
* OpenVas
* Qualys
* Tenable

智能上传的独特之处在于，它可以将扫描文件中的发现项拆分到不同的产品中。这在基础设施扫描场景中很有意义，因为这些发现项可能适用于许多不同的团队、具有不同的隐性 SLA，或者由于在基础设施中被发现的位置不同而需要包含在不同的报告中。

智能上传通过根据扫描中发现的端点对传入的发现项进行分类来处理这一问题。起初，这些发现项需要手动分配，或从未分配发现项列表中导向正确的产品。但是，一旦某个发现项被分配到某个产品，所有共享同一端点或主机的后续发现项都会被发送到同一个产品。

## 智能上传菜单选项

智能上传菜单存储在侧边栏的一个可折叠部分中。

* **添加发现项允许您导入新的扫描文件，类似于 DefectDojo 的导入扫描方法**
* **未分配发现项列出了所有尚未分配到产品的智能上传发现项。**

## 未分配发现项

智能上传完成后，任何未根据其端点自动分配到产品的发现项都会被放入**未分配发现项**列表中。对于给定工具的首次智能上传，尚没有任何分配发现项的方法，因此该文件中的每个发现项都会被发送到此页面进行分类。

未分配发现项不包含在产品层级结构中，在被分配之前不会出现在报告、过滤器或指标中。

### 处理未分配发现项

![image](images/smart_upload_3.png)

您可以使用复选框选择一个或多个未分配发现项进行分类，并执行以下操作之一：

* **分配到新产品，这将创建一个新产品**
* **分配到现有产品，这将把发现项移动到现有产品中**
* **忽略所选发现项**，这将把该发现项从列表中移除

每当某个发现项被分配到新产品或现有产品时，它都会被放置在一个名为"Smart Upload"的专用测试活动中。该测试活动将包含一个根据扫描类型命名的测试（例如 Tenable Scan）。通过智能上传上传的、与这些端点匹配的后续发现项将被放置在该测试活动 \> 测试下。

### 已忽略的发现项

如果某个发现项被忽略，它将从未分配发现项列表中移除。但是，该发现项不会被记录在内存中，因此后续的扫描上传可能会导致该发现项再次出现在未分配发现项列表中。
