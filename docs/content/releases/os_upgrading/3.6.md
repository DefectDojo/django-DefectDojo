Check the [Release Notes](https://github.com/DefectDojo/django-DefectDojo/releases/tag/3.6.0) for the contents of the release.

The removal of the API-based (pull) parsers, Tool Types, Tool Configurations and API Scan Configurations moved from 3.5.0 to 3.6.0. The removal of the DefectDojo Pro Endpoints pages moved from 3.6.0 to 3.7.0 (January 2027). See [Deprecations](/releases/deprecations/) for what is removed and what is scheduled.

## Email addresses

* A new email address must not belong to another account, compared ignoring case. This applies to creating and editing users and to profile edits, in the UI and the API (v2 and v3), which now answer `400` with an `email` error for an address in use. Accounts that already share an address keep working; nothing is migrated.
* Users no longer change their own email address directly on **Profile**. Set `DD_EMAIL_CHANGE_CONFIRMATION_ENABLED=True` (with a working `DD_EMAIL_URL`) to let them change it through a confirmation link sent to the new address. With the setting off, which is the default, an administrator changes it for them. Superusers still change any email address directly. A user who manages users but is not a superuser cannot change their own email address through the user API (v2 or v3) either: it answers `400`, and the address is changed on **Profile**. See [Creating a new user](/admin/user_management/os__creating_new_users/#email-addresses).
