There are no special instructions for upgrading to 3.6.x. Check the [Release Notes](https://github.com/DefectDojo/django-DefectDojo/releases/tag/3.6.0) for the contents of the release.

The removal of the API-based (pull) parsers, Tool Types, Tool Configurations and API Scan Configurations moved from 3.5.0 to 3.6.0. The removal of the DefectDojo Pro Endpoints pages moved from 3.6.0 to 3.7.0 (January 2027). See [Deprecations](/releases/deprecations/) for what is removed and what is scheduled.
