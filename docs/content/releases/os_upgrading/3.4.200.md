## DefectDojo Pro: the classic sidebar is removed

The reorganized sidebar is now the only navigation in the DefectDojo Pro UI. The classic
sidebar and the **Menu 2.0** toggle on the Feature Flags page are removed. This change applies
to DefectDojo Pro only. The open source UI is unaffected.

### What you need to do

Nothing. An instance that was still on the classic layout moves to the reorganized sidebar on
upgrade. Every page keeps its URL, so bookmarks and links continue to work. The
[Sidebar](/navigation/pro__sidebar/) page lists where each page now sits, and **Cmd+K** /
**Ctrl+K** finds any page by name.

The **Enable Calendar** checkbox in System Settings, which only applied to the classic sidebar,
is also gone. Use the **Calendar** flag on the Feature Flags page instead.

For more information, check the [Release Notes](https://github.com/DefectDojo/django-DefectDojo/releases/tag/3.4.200).
