Généralement, la plupart des constatations de votre environnement seront importées depuis d’autres outils de sécurité. Si vous le souhaitez, vous pouvez également ajouter des constatations manuelles si vous avez des vulnérabilités ou des tâches à gérer qui n’ont pas été créées à partir d’un outil d’analyse.

1. Depuis la barre latérale de DefectDojo, ouvrez le lien Nouvelle constatation en cliquant sur **Gérer \> Constatations \> Nouvelle constatation**.  
​
![image](images/Creating_Findings_Manually.png)
  
2. Cela ouvre le formulaire **Nouvelle constatation**, que vous pouvez remplir avec toutes les informations pertinentes relatives à votre constatation. Vous devrez associer cette constatation à un test préalablement créé dans DefectDojo.

![image](images/Creating_Findings_Manually_2.png)
