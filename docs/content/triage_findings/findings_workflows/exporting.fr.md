Les pages affichant une liste de constatations ou une liste d’engagements proposent une option d’exportation CSV et Excel dans le menu déroulant en haut à droite.

## Exporter les constatations

Depuis n’importe quelle page de liste de constatations, ouvrez le menu déroulant dans le coin supérieur droit pour exporter les constatations visibles au format CSV ou Excel.

## Exporter les engagements

La liste des engagements peut également être exportée au format CSV ou Excel à l’aide du même menu déroulant sur la page de liste des engagements.
