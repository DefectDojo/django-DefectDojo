**検出事項**、**エンゲージメント**、または**テスト**にファイルを添付して、補足的なコンテキストを提供できます。例えば、概念実証(PoC)のスクリーンショット、生のスキャナーレポート、
ネットワーク図、結果を裏付けるスプレッドシートなどです。

各オブジェクトはそれぞれ独自のファイルセットを保持し、1つのオブジェクトには**最大10ファイル**まで添付できます。

## Supported File Types

デフォルトでは、以下の拡張子が受け付けられます。

```
.txt  .pdf  .json  .xml  .csv  .yml  .png  .jpeg
.sarif  .xlsx  .doc  .html  .js  .nessus  .zip  .fpr
```

管理者は`DD_FILE_UPLOAD_TYPES`環境変数を使用してこのリストを変更できます。
リストにない拡張子のファイルをアップロードしようとすると拒否されます。

## How to Attach a File to a Finding

1. ファイルを添付したい検出事項を開きます。
2. 検出事項の右上にある**歯車(⚙)メニュー**をクリックし、**ファイルを追加**を選択します。
3. ファイルの**タイトル**を入力し、コンピューターからファイルを選択して保存します。

   ![The Add File action in the Finding gear menu, with the Files tab below](images/PRO_attach_files_menu.png)

同じ歯車メニューは**エンゲージメント**および**テスト**ページでも利用でき、これらのオブジェクトにも同じ方法で
ファイルを添付できます。

## Viewing and Downloading Files

添付されたファイルは、**検出事項の概要**の**ファイル**タブ(および
エンゲージメントとテストの該当セクション)に一覧表示されます。ファイルのタイトルをクリックするとダウンロードできます。

![The Files tab on a Finding listing an attached file](images/PRO_finding_files_tab.png)

アクセスは権限によってチェックされます。ファイルをダウンロードするには、親となる検出事項、
エンゲージメント、またはテストに対する**閲覧**権限が必要です。

## Deleting Files

ファイルを削除するには、**ファイル**タブでそのファイルの行メニュー(**⋮**アイコン)を開き、
**ファイルを削除**を選択します。同じメニューには、添付ファイルの名前を変更するための**ファイル名を編集**も用意されています。
