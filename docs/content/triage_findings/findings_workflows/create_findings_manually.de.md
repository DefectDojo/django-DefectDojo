Normalerweise werden die meisten Befunde in Ihrer Umgebung aus anderen Sicherheitswerkzeugen importiert. Wenn Sie möchten, können Sie zusätzlich Befunde manuell anlegen, etwa für Schwachstellen oder Arbeiten, die Sie verwalten möchten und die nicht aus einem Scan-Tool stammen.

1. Öffnen Sie in der DefectDojo-Seitenleiste den Link für einen neuen Befund über **Verwalten \> Befunde \> Neuer Befund**.  
​
![image](images/Creating_Findings_Manually.png)
  
2. Dadurch öffnet sich das Formular **Neuer Befund**, das Sie mit allen relevanten Informationen zu Ihrem Befund ausfüllen können. Sie müssen diesen Befund einem bereits in DefectDojo erstellten Test zuordnen.

![image](images/Creating_Findings_Manually_2.png)
