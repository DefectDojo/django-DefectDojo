Offboarding Export gives a departing customer a full copy of their DefectDojo Pro data in one zip file, generated by the instance itself, so the hand-off is consistent, logged, and the same every time.

Offboarding Export is a **DefectDojo Pro** feature. It is switched on for your instance by DefectDojo support as part of ending a subscription. Until then it is not present at all: there is no menu entry and no page. Once it is on, superusers find it under **Settings > License & Support > Offboarding Export**.

## What the export contains

Each export is a single zip file holding:

* **database.dump**: a PostgreSQL custom-format dump of the instance database (`pg_dump -Fc`).
* **media.tar**: every uploaded file (scan uploads, attachments, images).
* **scrubbed_tables.sql**: copies of the tables that mix your data with stored credentials, with the credential columns blanked. Load it after restoring the dump.
* **manifest.json**: the export id, who requested it and when, when it completed, the DefectDojo version, row counts for the main tables, the size and SHA-256 of each of the other three files, the list of what was scrubbed, and the restore commands.

**Stored credentials are not exported.** Passwords, API keys and tokens your instance holds for other systems (tool configurations, Jira and other integrations, SSO client secrets, SMTP), as well as API tokens, sessions, OAuth data, MFA seeds and the license, are either left out of the dump or blanked in the scrubbed copies. The manifest lists exactly which tables and columns that applies to. Your user records, including password hashes, are included unchanged.

## Requesting an export

1. Open **Settings > License & Support > Offboarding Export**.
2. Select **Request export** and confirm.
3. The export runs in the background. The page shows its status and refreshes on its own; a large instance can take a while.
4. When it completes, you get an in-app notification (and an email, if your notification settings send email) pointing to the page. The row shows the zip file name, its size and its SHA-256 checksum, and a **Download** button.

Generation is deliberately limited:

* Only one export can be running at a time.
* Only one export can complete every seven days. Requesting another inside that window returns the existing export instead of generating a new one.
* An instance can produce at most three exports. After that the request button disappears and the API answers that the limit is reached; contact DefectDojo support if you need another.

Every request, including refused ones, is recorded with the user and the time.

## Downloading the export

Select **Download** on a completed export. Only superusers of your instance can download it, and the check runs on every download, so there is no link to share or forward: the file streams straight from your instance to your browser over HTTPS. The zip is stored in DefectDojo's own object storage, encrypted at rest, in a bucket that only your instance can read; it is never pushed to a location you supply. The zip itself has no password.

A large download that is interrupted can be resumed. Every download that starts is counted and shown on the page.

Compare the SHA-256 shown on the page with the digest of the file you downloaded:

```bash
sha256sum defectdojo-offboarding-export-*.zip
```

After unzipping, `manifest.json` lists the SHA-256 of each file inside, so you can check those too.

## Restoring

`manifest.json` repeats these steps.

```bash
unzip defectdojo-offboarding-export-*.zip
createdb defectdojo
pg_restore --no-owner --no-privileges -d defectdojo database.dump
psql -d defectdojo -f scrubbed_tables.sql
tar -xf media.tar -C /path/to/media
```

The dump is produced with the PostgreSQL client that ships in the DefectDojo image; restore it with a `pg_restore` of the same or a newer major version.

## Retention

An export can be downloaded for 10 days after it completes, then it is deleted automatically. The page shows the hold date and, after deletion, when the zip was removed. DefectDojo support can extend the hold on request.
