> **尚未提供:** 共享传感器遥测数据目前还无法开启,无论是在 DefectDojo Cloud 上还是在自托管实例上,也无论如何配置。本页介绍该功能发布后的工作方式。

共享传感器遥测数据让实例可以向 DefectDojo 的威胁情报服务发送经过匿名化的**传感器命中事件**。一次命中是指您主机上的传感器做出的一次与某个 CVE 相关联的检测。共享的命中会告诉情报服务哪些漏洞正在野外被利用,这些证据会通过威胁情报源传递给每一个实例。

共享是 **DefectDojo Pro** 功能。它**默认关闭**,在超级用户开启之前不会发送任何内容。

## 共享哪些内容,不共享哪些内容

每个事件只包含以下四个值,不含其他任何内容:

| 字段 | 含义 |
| --- | --- |
| CVE | 匹配的检测规则所标记的 CVE |
| 时间 | 看到该命中的小时,以 UTC 表示。不发送分钟和秒 |
| 来源 | 最多包含命中来源的国家和网络(ASN)。常常为空 |
| 贡献者 ID | 一个每个自然月都会更换的随机标识符 |

事件绝不会包含有效载荷或请求正文、主机名、IP 地址、用户名、命令行、资产名称、公司名称、检测规则的名称或标识符,也不会包含您实例的名称或 URL。只有当您的实例配置为查询来源时,才会填写来源,而且只针对公共地址。此时 DefectDojo 会在您的实例上确定国家和网络,并在发送任何内容之前就地丢弃该地址。

规则标识符是有意省略的:您自己编写的规则可以使用任何名称,包括您公司的名称、某台主机的名称或某个人的名字。

事件会连同您实例的许可证密钥一起交付给 DefectDojo,情报服务据此接收这些事件。密钥随交付一起发送,而不在事件内部。

借助贡献者 ID,情报服务可以统计一个月内有多少个不同的实例看到了某个 CVE。它是随机生成的,每个月都会被新的 ID 替换,而且无法从新 ID 推算出旧 ID。

只会发送开启共享之后、且在最近 24 小时内的命中。关闭共享会删除所有仍在等待发送的事件,并丢弃贡献者 ID;合同条款发生变更时也是如此。再次开启共享时,会使用新的贡献者 ID。

## 开启之前

共享受您与 DefectDojo 所签合同中的一项条款约束。卡片会显示您开启共享时所接受的**合同条款版本**,在该版本在您的实例上可用之前,无法开启共享。

合同条款会在共享功能可用之前发布。

如果 DefectDojo 之后发布了该条款的新版本,共享会自动暂停。卡片会给出提示,按旧版本等待发送的事件会被删除,在超级用户按新版本重新开启共享之前,不会发送任何内容。共享暂停期间,复选框一开始是未勾选状态,因此只有再次勾选才会接受新版本。随后共享会重新开始,并使用新的贡献者 ID。

在离线(气隙)实例、公共演示环境或沙盒中,共享始终不可用。

## 开启或关闭共享

1. 以超级用户身份登录,打开 **Settings > System Settings**。
2. 滚动到页面底部的 **Sensor Telemetry** 卡片。
3. 阅读共享的内容以及卡片上显示的合同条款版本。如果您的实例配置了条款的地址,卡片会在版本旁边提供链接(**Read the contract term**)。
4. 勾选 **Share Sensor Hit Events**,然后选择 **Submit**。要停止共享,取消勾选该复选框并选择 **Submit**。

每次更改都会连同做出更改的用户一起记录在审计日志中。

## 卡片显示的内容

* **Sharing**:Off、On、Paused(合同条款已变更)、On, Not Sending(未配置情报端点或许可证密钥;卡片会说明缺少哪一项)或 Not Available。
* **Events Shared**、**Events Waiting** 和 **Events Dropped**:已交付、排队中或已丢弃的事件数量。无法交付的事件最多重试一天,之后会被丢弃。
* **Last Shared**:最近一次交付事件的时间。
* **CVE 列表**:您的传感器观测到的 CVE,最多显示最近看到的 200 个,包括命中次数、已共享的次数,以及每个 CVE 首次和最后一次被看到的时间。卡片标题显示观测到的 CVE 总数。无论是否开启共享,这份列表都会保存在您的实例上。
* **Seen Elsewhere**:其他参与共享的实例是否也看到了同一个 CVE。只有在共享开启且情报服务有响应时才会填写,而且只针对您的实例已经共享过的 CVE:查询会指明 CVE,因此只在开启共享之前看到过的 CVE 永远不会被查询。否则,表格下方的一行会说明为什么为空,例如实例上没有配置情报端点或许可证密钥。

当您的实例拥有传感器、观测到过 CVE 或已为共享做过配置时,卡片就会出现。

## 自托管配置

在自托管实例上,由运维人员设置以下环境变量。它们默认都为空,为空即表示关闭。

| 变量 | 用途 |
| --- | --- |
| `DD_SENSOR_TELEMETRY_CONTRACT_TERM_VERSION` | 合同条款的版本。没有它就无法开启共享 |
| `DD_SENSOR_TELEMETRY_CONTRACT_TERM_URL` | 可选。可以阅读合同条款的 HTTPS 地址。卡片会在版本旁边提供该链接 |
| `DD_SENSOR_TELEMETRY_ENDPOINT` | 情报服务的 HTTPS 基础 URL。没有它就绝不会发起任何网络调用 |
| `DD_THREAT_INTEL_LICENSE_KEY` | 每次交付时发送的许可证密钥。没有它就不会发起网络调用 |
| `DD_SENSOR_TELEMETRY_SOURCE_RESOLVER` | 可选。一个函数的点分 Python 路径,该函数把公共来源地址转换为国家和 ASN。DefectDojo 不附带任何国家或 ASN 数据库,因此没有它时事件不包含来源 |
