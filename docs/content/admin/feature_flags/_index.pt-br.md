Muitos recursos do DefectDojo Pro são lançados atrás de uma feature flag, para que você possa
adotá-los quando estiver pronto, em vez de na versão em que são introduzidos.

Feature Flags é um recurso do DefectDojo Pro. O DefectDojo open-source não possui uma superfície de feature
flags.

* [Feature Flags](./pro__feature_flags/) — veja todos os recursos opcionais, ative e desative recursos, e
  entenda por que um recurso pode estar indisponível na sua instância.
