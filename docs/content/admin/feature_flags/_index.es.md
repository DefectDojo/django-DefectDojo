Muchas funciones de DefectDojo Pro se publican detrás de un feature flag, de modo que pueda adoptarlas cuando esté listo en lugar de tener que hacerlo en la versión que las introduce.

Feature Flags es una función de DefectDojo Pro. DefectDojo de código abierto no dispone de una superficie de feature flags.

* [Feature Flags](./pro__feature_flags/) — vea todas las funciones opcionales, active y desactive funciones, y entienda por qué una función podría no estar disponible en su instancia.
