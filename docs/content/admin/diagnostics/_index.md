When something does not arrive — a ticket that was never created, a scan that never imported, a user who cannot sign in — the evidence used to live in whichever subsystem happened to own the attempt. Diagnostics records every one of those attempts against a single ledger, so the question "why did that not happen?" is one page instead of eight.

Diagnostics is a **DefectDojo Pro** feature.

* [Diagnostics](./pro__diagnostics/) — what is recorded, how to read and filter the ledger, how credentials are kept out of it, who can see the technical detail, and how long records are kept.
