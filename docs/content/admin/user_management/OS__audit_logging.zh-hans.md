DefectDojo 的审计日志可以通过几种不同的方式访问。

## 单个对象的日志
* DefectDojo 的每个对象都有一份关联的对象历史记录（Object History），可通过 UI 访问。系统会为资产（Assets）、测试活动（Engagements）、测试（Tests）、发现项（Findings）和端点（Endpoints），以及风险接受（Risk Acceptances）记录这些历史。

在经典（开源）用户界面中，可以在对象视图内的 ☰ 汉堡菜单下找到对象日志。
