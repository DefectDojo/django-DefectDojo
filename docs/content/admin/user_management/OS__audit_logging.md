Audit logs for DefectDojo can be accessed in a few different ways.

## Individual Object Logs
* DefectDojo objects each have an associated Object History, which can be accessed through the UI.  These histories are recorded for Assets, Engagements, Tests, Findings and Endpoints, as well as Risk Acceptances.

In the Classic (Open-Source) UI, Object Logs are found under the ☰ hamburger menu in an object's view.
