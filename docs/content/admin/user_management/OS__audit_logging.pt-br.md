Os logs de auditoria do DefectDojo podem ser acessados de algumas formas diferentes.

## Logs individuais de objeto
* Cada objeto do DefectDojo tem um Histórico do Objeto associado, que pode ser acessado pela interface.  Esses históricos são registrados para Ativos, Engajamentos, Testes, Achados e Endpoints, além das Aceitações de risco.

Na interface Clássica (Open Source), os Logs de Objeto ficam no menu ☰ hambúrguer na visualização de um objeto.
