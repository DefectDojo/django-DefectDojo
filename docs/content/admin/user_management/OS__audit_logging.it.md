I log di audit di DefectDojo sono accessibili in diversi modi.

## Log dei singoli oggetti
* Ogni oggetto di DefectDojo ha una Object History associata, accessibile tramite l'interfaccia utente. Queste cronologie vengono registrate per Asset, Engagement, Test, Riscontri ed Endpoint, oltre che per le Accettazioni del rischio.

Nell'interfaccia Classic (Open-Source), i Log degli oggetti si trovano nel menu ☰ (hamburger) nella vista di un oggetto.
