The Appearance settings control how the DefectDojo Pro UI looks for everyone on your instance: which theme preset it starts from, and any colors you customize on top of it.

Appearance is a DefectDojo Pro feature. Open-source DefectDojo does not have an Appearance page.

* [Appearance](./pro__appearance/): pick a theme preset, customize colors for light and dark mode, and check that text stays readable.
