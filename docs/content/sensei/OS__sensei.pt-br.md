<span style="background-color:rgba(242, 86, 29, 0.3)">Nota: o Sensei é um recurso exclusivo do DefectDojo Pro.</span>

O **Sensei**, o recurso de **scan-and-fix** com IA do DefectDojo para repositórios de código-fonte, está disponível somente no **DefectDojo Pro**. Ele não faz parte da edição open-source.

Com o Sensei, o DefectDojo Pro pode:

- Escanear seus repositórios do GitHub e importar os resultados como achados.
- Abrir pull requests que **remediam** esses achados com um modelo de linguagem de grande porte (large language model), usando um fluxo de aprovação com pré-visualização antecipada (nada é executado até que você aprove).
- Iniciar uma correção a partir da tabela de achados, de candidatos de correção automática em preparação (staged), ou com um comentário `/fix` em um pull request.

## Veja a documentação completa do Sensei

O guia completo do Sensei faz parte da documentação **Pro**. Alterne o seletor de versão da documentação (no topo da navegação à esquerda) para **Pro** para lê-lo:

- **About Sensei:** o que é e como funciona o scan-and-fix hospedado
- **Set Up Sensei:** conecte um GitHub App e integre um repositório
- **Fixing Findings with Sensei:** escaneie, faça a triagem dos candidatos e abra PRs de correção
- **Sensei Reference:** status, cotas e solução de problemas

Para saber mais sobre o DefectDojo Pro, visite [defectdojo.com](https://www.defectdojo.com/) ou entre em contato com sua equipe de conta do DefectDojo.
