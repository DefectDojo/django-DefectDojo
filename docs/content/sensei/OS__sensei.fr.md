<span style="background-color:rgba(242, 86, 29, 0.3)">Remarque : Sensei est une fonctionnalité exclusive à DefectDojo Pro.</span>

**Sensei**, la fonctionnalité de **scan-and-fix** de DefectDojo alimentée par l'IA pour les dépôts de code source, est disponible uniquement dans **DefectDojo Pro**. Elle ne fait pas partie de l'édition open source.

Avec Sensei, DefectDojo Pro peut :

- Scanner vos dépôts GitHub et importer les résultats sous forme de Constatations.
- Ouvrir des pull requests qui **remédient** à ces Constatations à l'aide d'un grand modèle de langage, selon un flux de validation avec aperçu préalable (rien ne s'exécute tant que vous n'avez pas approuvé).
- Démarrer une correction depuis le tableau des Constatations, depuis les candidats de correction automatique en attente, ou avec un commentaire `/fix` sur une pull request.

## Consultez la documentation complète de Sensei

Le guide complet de Sensei fait partie de la documentation **Pro**. Basculez le sélecteur de version de la documentation (en haut de la navigation de gauche) sur **Pro** pour le consulter :

- **About Sensei :** ce que c'est et comment fonctionne le scan-and-fix hébergé
- **Set Up Sensei :** connecter une GitHub App et intégrer un dépôt
- **Fixing Findings with Sensei :** scanner, trier les candidats et ouvrir des PR de correction
- **Sensei Reference :** statuts, quotas et dépannage

Pour en savoir plus sur DefectDojo Pro, visitez [defectdojo.com](https://www.defectdojo.com/) ou contactez votre équipe de compte DefectDojo.
