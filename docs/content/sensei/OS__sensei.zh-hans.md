<span style="background-color:rgba(242, 86, 29, 0.3)">注意：Sensei 仅是 DefectDojo Pro 版专属功能。</span>

**Sensei** 是 DefectDojo 面向源代码代码库、由 AI 驱动的**扫描并修复**功能，仅在 **DefectDojo Pro** 中提供，并不属于开源版的一部分。

借助 Sensei，DefectDojo Pro 可以：

- 扫描您的 GitHub 代码库，并将结果作为发现项导入。
- 使用大语言模型开启拉取请求以**修复**这些发现项，采用先预览后批准的工作流（在您批准之前不会执行任何操作）。
- 可以从发现项表格、已暂存的自动修复候选项，或通过在拉取请求中添加 `/fix` 评论来启动修复。

## 查看完整的 Sensei 文档

完整的 Sensei 指南是 **Pro** 文档的一部分。请将文档版本切换开关（位于左侧导航顶部）切换到 **Pro** 以阅读：

- **About Sensei（关于 Sensei）：** Sensei 是什么，以及托管式扫描并修复的工作原理
- **Set Up Sensei（设置 Sensei）：** 连接 GitHub App 并接入代码库
- **Fixing Findings with Sensei（使用 Sensei 修复发现项）：** 扫描、分类候选项并开启修复 PR
- **Sensei Reference（Sensei 参考）：** 状态、配额与故障排查

如需了解更多关于 DefectDojo Pro 的信息，请访问 [defectdojo.com](https://www.defectdojo.com/) 或联系您的 DefectDojo 客户团队。
