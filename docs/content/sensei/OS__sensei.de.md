<span style="background-color:rgba(242, 86, 29, 0.3)">Hinweis: Sensei ist eine ausschließlich für DefectDojo Pro verfügbare Funktion.</span>

**Sensei**, die KI-gestützte **Scan-and-Fix**-Funktion von DefectDojo für Quellcode-Repositories, ist ausschließlich in **DefectDojo Pro** verfügbar. Sie ist nicht Teil der Open-Source-Edition.

Mit Sensei kann DefectDojo Pro:

- Ihre GitHub-Repositories scannen und die Ergebnisse als Befunde importieren.
- Pull Requests öffnen, die diese Befunde mithilfe eines Large Language Models **beheben**, über einen Preview-first-Freigabe-Workflow (nichts wird ausgeführt, bevor Sie zustimmen).
- Eine Behebung aus der Befundtabelle, aus vorgemerkten Auto-Fix-Kandidaten oder mit einem `/fix`-Kommentar an einem Pull Request starten.

## Die vollständige Sensei-Dokumentation ansehen

Der vollständige Sensei-Leitfaden ist Teil der **Pro**-Dokumentation. Stellen Sie den Dokumentationsversions-Umschalter (oben in der linken Navigation) auf **Pro**, um ihn zu lesen:

- **About Sensei:** was es ist und wie das gehostete Scan-and-Fix funktioniert
- **Set Up Sensei:** eine GitHub App verbinden und ein Repository onboarden
- **Fixing Findings with Sensei:** scannen, Kandidaten triagieren und Fix-PRs öffnen
- **Sensei Reference:** Status, Kontingente und Fehlerbehebung

Um mehr über DefectDojo Pro zu erfahren, besuchen Sie [defectdojo.com](https://www.defectdojo.com/) oder wenden Sie sich an Ihr DefectDojo-Account-Team.
