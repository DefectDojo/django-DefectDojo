Besoin d'aide avec DefectDojo ? Voici plusieurs façons d'obtenir de l'assistance.

## Support Open-Source

Les utilisateurs Open-Source peuvent obtenir de l'aide et des conseils via nos canaux communautaires.

Pour les utilisateurs Open-Source, le moyen le plus rapide d'obtenir de l'aide est le [Canal Slack OWASP](https://owasp.org/slack/invite).  Les membres de notre communauté sont actifs sur le **canal # defectdojo** et peuvent vous aider face aux problèmes que vous rencontrez.

Pour signaler un bug, vous pouvez ouvrir un ticket sur notre [GitHub](https://github.com/DefectDojo/django-DefectDojo).

Consultez notre [Site communautaire](https://defectdojo.com/open-source) pour plus d'informations.

## Support DefectDojo Pro

Les abonnements DefectDojo Pro incluent un support complet de l'équipe DefectDojo, Inc. pendant la période d'essai initiale et au-delà.

### E-mail

Les clients/utilisateurs Pro peuvent toujours contacter notre équipe directement par e-mail à [support@defectdojo.com](mailto:support@defectdojo.com) pour obtenir de l'aide.

### Depuis DefectDojo

Sur une instance auto-hébergée, un superutilisateur peut ouvrir **Settings > Contact Support** depuis la barre latérale gauche. La page indique l'adresse à laquelle écrire.

Sur DefectDojo Cloud, utilisez l'adresse e-mail ci-dessus ou le Cloud Portal ci-dessous.

### Depuis le Portail Cloud

Vous pouvez également contacter notre équipe support depuis votre Portail Cloud :

1. en cliquant sur **Contact Us** (dans la barre latérale gauche)
2. ou via **<https://cloud.defectdojo.com/resources/contact>**.
