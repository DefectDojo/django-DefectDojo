La page de métriques **Executive Insights** fournit une vue agrégée du risque de sécurité applicatif à l'échelle de votre organisation. Conçu pour un usage au niveau exécutif, ce tableau de bord se concentre exclusivement sur les Organisations et les Actifs, en mettant l'accent sur les tendances et les résultats plutôt que sur les Constatations individuelles.

![image](images/pro_dashboards_1.png)

Dans Executive Insights, les Utilisateurs peuvent sélectionner une période, une Organisation, un Actif ou une Étiquette dans la liste de filtres, ce qui alimente un tableau adjacent avec les Constatations correspondantes. Cela modifie également les résultats affichés dans les différents graphiques ci-dessous.

Si aucun filtre n'est sélectionné, le tableau affiche le statut de toutes les Organisations, Actifs et Étiquettes.

Le premier tableau offre une vue d'ensemble de votre posture de sécurité globale. Deux tableaux distincts sont également disponibles pour vos Organisations et vos Actifs.

Les chiffres se remplissent dans chaque tableau en fonction des filtres appliqués. Cliquer sur un chiffre comportant un lien hypertexte dans une cellule ouvre un nouvel onglet avec un tableau de Constatations correspondant.
