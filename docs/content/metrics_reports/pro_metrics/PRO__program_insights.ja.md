**プログラムインサイト** メトリクスページでは、個々の検出事項ではなくプログラム全体のパフォーマンスに焦点を当て、アプリケーションセキュリティプログラム全体の有効性と成熟度を評価します。

![画像](images/pro_dashboards_3.png)

テスト実施状況の内訳に加え、重複排除機能や再インポート機能がノイズ削減、効率向上、累積的なコスト削減にどのように影響しているかを示し、セキュリティプロセスが意図したとおりに機能していることを確認できます。
