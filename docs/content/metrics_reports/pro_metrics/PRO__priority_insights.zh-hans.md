**优先级洞察**指标页面展示根据风险、严重程度、可利用性或自定义评分确定的最关键发现项，帮助团队了解在任何时刻哪些漏洞构成的威胁最大，从而有针对性地集中精力应对。

除了各种图表之外，优先级洞察还包含四个可点击的弹出窗口，点击后会在新标签页中打开一张表格，展示这四个弹出窗口所代表的全部数据：

* 紧急风险发现项总数
* 需处理风险发现项总数
* 中等风险发现项总数
* 发现项平均优先级

该页面还内置了一张按 AppSec 或 SOC 排列的优先级发现项表格，用户可以进一步筛选、交互并查看与各个发现项相关的数据。表格内容可以导出为 CSV 文件或快速报告，导出前还可以添加其他多种列。
