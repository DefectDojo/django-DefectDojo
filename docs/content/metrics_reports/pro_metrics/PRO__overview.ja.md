DefectDojo Pro の UI には、現在のセキュリティ体制を可視化するためのさまざまなメトリクスダッシュボードが用意されています。各ダッシュボードにより、組織内のさまざまな階層の関係者が、生データを解釈したり個々の検出事項を確認したりすることなく、的確な意思決定を行えるようになります。これらのダッシュボードには次のものが含まれます。
* [エグゼクティブインサイト](/metrics_reports/pro_metrics/pro__executive_insights/#main-content)
* [優先度インサイト](/metrics_reports/pro_metrics/pro__priority_insights/#main-content)
* [プログラムインサイト](/metrics_reports/pro_metrics/pro__program_insights/#main-content)
* [改善インサイト](/metrics_reports/pro_metrics/pro__remediation_insights/#main-content)
* [ツールインサイト](/metrics_reports/pro_metrics/pro__tool_insights/#main-content)

## メトリクス機能

各ダッシュボードの詳細を説明する前に、すべてのダッシュボードに共通する、確認しておく価値のある点をいくつか紹介します。

### フィルタリング

すべてのメトリクスは、期間、組織、アセット、タグでフィルタリングできます。フィルタを希望どおりに調整した後、それを有効にするには「フィルタを適用」をクリックする必要があります。現在のフィルタ条件でダッシュボード上のすべてのチャート、テーブル、グラフを PDF としてエクスポートしたい場合は、「PDF としてエクスポート」をクリックしてください。

フィルタリングの期間は過去1年までに限定されていますが、それ以外にも過去7日、14日、30日、90日、180日の範囲に調整できます。

フィルタパラメータは URL に反映されるため、さまざまなフィルタパラメータを持つ複数のページをブックマークできます。これは、素早く参照したい場合や、特定の種類のレポートを継続的に生成したい場合に役立ちます。

### サブメニュー

各グラフの右上には ⋮ ケバブメニューがあり、次の機能を備えています。
* 強制更新 — データ内の新しい更新を手動で反映します。
* グラフを拡大 — 同じチャートをより大きなポップアップモーダルで開きます。
* グラフを SVG としてダウンロード — チャートを SVG ファイルとしてダウンロードします。
* テーブルとして表示 — チャートのデータをテーブル形式で表示します。
    * テーブルの各列はクリックすることで昇順または降順の表示に切り替えられます。各テーブルをダウンロードすることもできます。

![ケバブメニューの内容](images/metrics_image2.png)

### アクセス

メトリクスセクションには、各ユーザーが閲覧権限を持つ組織およびアセットのデータのみが表示されます。単一のアセットに限定されたアクセス権を持つユーザーは、そのアセットに関するメトリクスのみを閲覧でき、親組織内の他のアセットへのアクセス権がない場合、それらのアセットのデータはメトリクスに表示されません。

### グラフ内のデータの表示

折れ線グラフの X 軸は、常に現在の期間フィルタを表します。折れ線グラフにカーソルを合わせると、その時点における Y 軸の数値件数を示すモーダルが表示されます。

![グラフのポップアップモーダル](images/metrics_image3.png)

### 結果の切り替え

ユーザーは、各チャート上部にある該当する色や名前をクリックすることで、特定のカテゴリの検出事項をチャート内で表示・非表示に切り替えることができます。

たとえば、以下の深刻度別アクティブ検出事項チャートで、高または重大の深刻度を持つ検出事項のみを表示したい場合は、上部の「中」「低」「情報」をクリックしてそれらの結果をチャートから除外します。「中」「低」「情報」を再度クリックすると、それらの結果が再び表示されます。
