The Dashboard is the front page of DefectDojo — a summary of your team's performance and a launchpad for monitoring the areas that matter to you.

## Open source vs. DefectDojo Pro

El funcionamiento del panel depende de la edición que utilices:

| | Open Source | DefectDojo Pro |
|---|---|---|
| **Panel de inicio** | Un único Panel principal fijo para todos | Paneles **personalizables** por usuario |
| **Elegir qué se muestra** | El superusuario activa o desactiva un conjunto fijo de gráficos | Cada usuario añade, configura y organiza **widgets** |
| **Varios paneles con nombre** | No | Sí — crea y cambia entre cualquier número de **diseños** |
| **Compartir / clonar / definir uno predeterminado** | — | Sí — publica diseños para tu equipo, clona plantillas y define tu predeterminado |
| **API REST + automatización con LLM** | — | Sí — descubre el catálogo, crea diseños y renderiza los datos de los widgets |

En resumen: **open source** ofrece a todos los usuarios el mismo Panel principal integrado, con un conjunto fijo de componentes. **DefectDojo Pro** permite que cada usuario cree sus propios paneles a partir de widgets, los comparta y controle todo el sistema desde la interfaz, la API REST o un LLM.
