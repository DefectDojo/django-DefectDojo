**我的工作**只回答一个问题：有什么在等着我处理？这是一个按用户划分的视图——同一个页面会向每个人展示各自的队列。

在左侧边栏中通过 **仪表板 > 我的工作** 打开该页面。

## 队列

| 队列 | 显示内容 |
| --- | --- |
| **分配给我** | 个人被分配的发现项。仅在启用**工作分配**功能时显示，否则隐藏。 |
| **我的团队队列** | 由您所属的组拥有的发现项。所有者是组级别的，因此这里显示的是您团队的工作，而非专属于您个人的工作。 |
| **等待我审核** | 系统请求您审核、且审核仍处于开放状态的发现项。 |
| **我发起的审核** | 您发起、但尚未有人处理完成的审核。 |
| **我的风险接受** | 由您拥有、且尚未有人处理的风险接受。已过期的项目会持续列出，直到被处理为止。 |

每个队列都是完整的发现项或风险接受列表，因此常规的筛选、排序和列控制均可正常使用，且每个标签页都会记住自己的列布局。

所有内容均受您权限范围的限定——我的工作绝不会向您展示您原本无权查看的内容。

## 在仪表板中使用

相同的内容也可以作为**我的工作**小组件用于[自定义仪表板](../custom-dashboards/)，这样您就可以将自己的队列与其他指标并排展示。添加该小组件后，选择要显示的队列以及每个队列应显示的行数。

在**个人**类别下还有一个现成的**我的工作**仪表板模板，将该小组件与 SLA 倒计时和近期动态搭配在一起。

## 为何使用队列而非通知

通知可能会被错过、被过滤，或是在您没注意的时候送达。我的工作是更持久可靠的版本：无论通知是否送达，任何等待您处理的事项都会出现在这里。

这也是为什么可以缩小部分通知范围而不会遗漏工作。即使审核者已将其[审核请求通知的范围限定](/admin/notifications/about_notifications/#narrowing-review-request-notifications-pro)在特定资产上，仍然会在**等待我审核**中看到每一个请求——被抑制的只是通知，而不是工作本身。
