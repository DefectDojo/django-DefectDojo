**マイワーク**が答える問いはただ一つ、「自分を待っているものは何か」です。これはユーザーごとのビューで、同じページが各人に自分専用のキューを表示します。

左サイドバーの **Dashboards > My Work** から開きます。

## キュー

| キュー | 表示内容 |
| --- | --- |
| **自分に割り当て済み** | 自分個人に割り当てられた検出事項です。**Work Assignment** 機能が有効になっていない限り非表示です。 |
| **自分のチームのキュー** | 自分が所属するグループが所有する検出事項です。所有者はグループ単位のため、これは自分個人ではなくチームの作業です。 |
| **レビュー待ち** | 自分がレビューを依頼され、そのレビューがまだ完了していない検出事項です。 |
| **自分が依頼したレビュー** | 自分が開始したものの、まだ誰も完了していないレビューです。 |
| **自分のリスク受容** | 自分が所有しているものの、まだ誰も対応していないリスク受容です。期限切れのものも、対応されるまで一覧に残ります。 |

各キューは完全な検出事項またはリスク受容の一覧であるため、通常のフィルタリング、並べ替え、列の操作がすべて機能し、各タブは自分自身の列レイアウトを記憶します。

すべては自分の権限の範囲内に限定されます。マイワークは、本来閲覧できないはずのものを表示することはありません。

## ダッシュボード上で

同じ内容は[カスタムダッシュボード](../custom-dashboards/)向けの**マイワーク**ウィジェットとしても利用でき、自分のキューを他の指標と並べて配置できます。ウィジェットを追加し、表示するキューと各キューの表示行数を選択してください。

**Personal**カテゴリーには、このウィジェットとSLAバーンダウンおよび最近のアクティビティを組み合わせた、既製の**マイワーク**ダッシュボードテンプレートも用意されています。

## 通知ではなくキューを使う理由

通知は見逃されたり、フィルタリングされたり、見ていないときに届いたりすることがあります。マイワークは、その永続的な代替手段です。通知が届いたかどうかにかかわらず、自分を待っているものはすべてここにあります。

そのため、一部の通知は作業を失うことなく絞り込むことができます。[レビュー依頼の通知を特定のアセットに絞り込んだ](/admin/notifications/about_notifications/#narrowing-review-request-notifications-pro)レビュアーであっても、**レビュー待ち**にはすべての依頼が引き続き表示されます。抑制されるのは通知だけで、作業ではありません。
