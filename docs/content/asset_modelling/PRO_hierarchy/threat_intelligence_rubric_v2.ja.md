> **まだ利用できません。** このページでは開発中の機能について説明しています。この機能は **Feature Flags** ページに表示されず、DefectDojo Cloudでもセルフホストのインスタンスでも、まだ有効にすることはできません。現在、すべての検出事項は[脅威インテリジェンス](../threat_intelligence/)で説明されているとおりにスコアリングされます。

[脅威インテリジェンス](../threat_intelligence/#スコアリングへの影響)は、悪用証跡をEPSSスケール上の**フロア**(下限)に変換します。検出事項の外部スコアは、その最も強い証跡が到達するフロア以上になります。このフロアの表を**ルーブリック**(rubric)と呼びます。Rubric v2はその次のバージョンです。各フロアの値はそのまま維持し、証跡の種類を1つ追加します。それは、**DefectDojoのアナリストがレビューして確認した悪用の報告**です。

## 変更点

| 証跡 | Priorityフロア(EPSS換算) |
|---|---|
| 確認済みの悪用証跡**と**、その背後にいる確認済みの名前が特定された脅威アクター(新規) | 45% |
| CISA KEVに掲載**かつ**ランサムウェアで使用 | 30% |
| KEVに掲載、実際に悪用されている、または**確認済みの悪用証跡**(確認済みのカナリア観測を含む)がある(新規) | 20% |
| 武器化された公開エクスプロイト(Metasploit / Exploit-DB) | 15% |
| Nuclei検出テンプレートが存在する | 12% |
| 公開PoCのみ | 8% |
| 悪用証跡なし | 変更なし |

フロアの値は現在と同じです。検出事項の外部スコアは引き続き、EPSS由来の値と最も高いフロアの大きい方が採用されるため、ルーブリックがスコアを引き下げることはありません。

実際には次のようになります。

- **「既知の悪用」のフロアに達する検出事項が増えます。** CISA KEVに掲載されていなくても、レビュー済みの悪用証跡(インシデントレポート、悪用を明記したベンダーのアドバイザリ、ハニーポットやカナリアでの観測)があるCVEには、KEV掲載と同じ20%のフロアが適用されます。
- **最上位のフロアに到達できるようになります。** Rubric v1では、45%のフロアにはフィードに含まれないベンダーのテレメトリが必要だったため、このフロアに達した検出事項はありませんでした。Rubric v2では、確認済みの名前が特定された脅威アクターが背後にいる確認済みの証跡によってのみ、このフロアに到達します。
- **弱くなるものはありません。** レビュー済みの証跡がなければ、脆弱性は現在とまったく同じようにスコアリングされます。ランサムウェアでの使用が示されたKEVエントリは30%のままです。CISAのランサムウェアフラグはアクターを特定していないためです。

フロアを引き上げ**ない**もの: 未レビューまたは却下された報告、PoC単独、スキャナーやベンダーの「エクスプロイトあり」フラグ(これらは現在と同様に表示されますが、証跡としては扱われません)。

## 有効化の前に

インスタンスをRubric v2に移行すると検出事項のPriorityが上がる可能性があるため、DefectDojoは移行前にその影響を測定します。インスタンスごとに、どれだけの検出事項がどのフロアからどのフロアへ移るか、そして移動ごとに最も多くの検出事項の背後にある脆弱性を確認します。Rubric v2がリリースされるまで、現在のPriorityはRubric v1のままです。
