DefectDojo 提供两个在线演示环境。两者均预加载了数据并可完整使用，运行的是最新版本的 DefectDojo。

演示服务器每天重置一次，并且是公开访问的；请勿在演示环境中放入敏感数据。

### 🔸 DefectDojo Pro 演示
您可以在 [pro.demo.defectdojo.com](https://pro.demo.defectdojo.com) 上试用 DefectDojo Pro

使用 `admin / 1Defectdojo@demo#appsec` 登录。

### 🔹 DefectDojo 社区版演示
您可以在 [demo.defectdojo.org](https://demo.defectdojo.org) 上试用我们的社区版

使用 `admin / 1Defectdojo@demo#appsec` 登录。
