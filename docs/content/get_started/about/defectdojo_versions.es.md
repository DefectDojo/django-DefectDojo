**DefectDojo Open-Source** es una plataforma de gestión de vulnerabilidades potente y gratuita, con importación básica, deduplicación, paneles básicos, acceso a la API e informes esenciales — ideal para equipos más pequeños o para quienes desean autoalojar y ampliar la herramienta usando recursos de la comunidad.

**DefectDojo Pro** se construye sobre esa base con funciones orientadas a la empresa, como paneles e informes avanzados, automatización y scripting mediante un motor de reglas, conectores a numerosas herramientas de seguridad, flujos de importación optimizados, soporte unificado de SOC y AppSec, una UI/UX mejorada, integración de IA, seguridad reforzada (SSO/MFA) y opciones de soporte premium.

| Función / Capacidad | DefectDojo Open-Source | DefectDojo Pro |
|---------------------|------------------------|----------------|
| Gestión de vulnerabilidades principal | ✔️ Importe, rastree y gestione hallazgos de más de 500 herramientas de seguridad | ✔️ Todo lo incluido en Open-Source, optimizado para escalar |
| Deduplicación de hallazgos | ✔️ Deduplicación estándar | ✔️ Deduplicación avanzada y configurable |
| API REST | ✔️ API REST completa | ✔️ API REST completa |
| Autenticación y control de acceso | ✔️ Autenticación local y RBAC básico | ✔️ SSO (SAML/OAuth), MFA, RBAC avanzado |
| Interfaz de usuario | ✔️ UI de la comunidad | ✔️ UI Pro moderna con mejoras de rendimiento |
| Paneles e informes | ✔️ Paneles e informes básicos | ✔️ Paneles avanzados y personalizables e informes ejecutivos |
| Automatización y flujos de trabajo | ❌ No incluido | ✔️ Motor de reglas y flujos de trabajo automatizados |
| Mejoras de importación | ❌ Solo importaciones estándar | ✔️ Importaciones en segundo plano, Smart Upload, Universal Parser, cargas por CLI |
| Integraciones de herramientas | ❌ Manual/mediante API | ✔️ **Conectores Upstream** integrados para herramientas populares de AppSec y de nube |
| Integración con Jira | ✔️ Incluido | ✔️ Incluido |
| Integraciones de gestión de proyectos | ❌ No incluido | ✔️ **Conectores Downstream** a **Jira**, **Azure DevOps**, **GitHub**, **GitLab**, **ServiceNow**, **Bitbucket**, **Shortcut**, **PagerDuty**, **Zendesk**, **ServiceDesk Plus** y **Freshservice** |
| Mejoras de hallazgos | ❌ No incluido | ✔️ Puntuación automática de KEV, EPSS y seguimiento de ransomware |
| Unificación de SOC y AppSec | ❌ Solo enfocado en AppSec | ✔️ Hallazgos unificados de AppSec y SOC |
| IA y funciones de próxima generación | ❌ No incluido | ✔️ Flujos de trabajo asistidos por IA, informes y soporte de MCP |
| Soporte | Soporte de la comunidad (GitHub, Slack, foros) | Soporte comercial con SLAs |
| Opciones de alojamiento | Autoalojado | Autoalojado o alojado en la nube |
