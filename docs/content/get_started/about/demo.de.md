Für DefectDojo stehen zwei Online-Demos bereit.  Beide sind mit Daten vorbefüllt, voll funktionsfähig und laufen mit der neuesten Version von DefectDojo.

Die Demo-Server werden täglich zurückgesetzt und sind öffentlich zugänglich; legen Sie keine sensiblen Daten in der Demo ab.

### 🔸 DefectDojo Pro Demo
DefectDojo Pro können Sie unter [pro.demo.defectdojo.com](https://pro.demo.defectdojo.com) testen

Melden Sie sich mit `admin / 1Defectdojo@demo#appsec` an.

### 🔹 DefectDojo Community Edition Demo
Unsere Community Edition können Sie unter [demo.defectdojo.org](https://demo.defectdojo.org) testen

Melden Sie sich mit `admin / 1Defectdojo@demo#appsec` an.
