Deux démos en ligne sont disponibles pour DefectDojo.  Les deux sont préchargées avec des données et sont pleinement fonctionnelles, exécutant la dernière version de DefectDojo.

Les serveurs de démo sont réinitialisés quotidiennement et sont accessibles publiquement ; ne placez pas de données sensibles dans la démo.

### 🔸 Démo DefectDojo Pro
DefectDojo Pro peut être testé sur [pro.demo.defectdojo.com](https://pro.demo.defectdojo.com)

Connectez-vous avec `admin / 1Defectdojo@demo#appsec`.

### 🔹 Démo de l'édition Community de DefectDojo
Notre édition Community peut être testée sur [demo.defectdojo.org](https://demo.defectdojo.org)

Connectez-vous avec `admin / 1Defectdojo@demo#appsec`.
