**DefectDojo Open-Source**は、コアとなるインポート機能、重複排除、基本的なダッシュボード、APIアクセス、必須のレポート機能を備えた、強力で無料の脆弱性管理プラットフォームです。小規模なチームや、コミュニティリソースを使ってツールを自己ホスティングし拡張したい方に最適です。

**DefectDojo Pro**は、その基盤の上に、高度なダッシュボードとレポート、ルールエンジンによる自動化とスクリプティング、多数のセキュリティツールへのコネクタ、最適化されたインポートワークフロー、SOCとAppSecの統合サポート、改善されたUI/UX、AI連携、強化されたセキュリティ(SSO/MFA)、プレミアムサポートオプションなど、エンタープライズ志向の機能を追加しています。

| Feature / Capability | DefectDojo Open-Source | DefectDojo Pro |
|---------------------|------------------------|----------------|
| コア脆弱性管理 | ✔️ 500以上のセキュリティツールから検出事項をインポート、追跡、管理 | ✔️ Open-Sourceのすべての機能をスケールに最適化 |
| 検出事項の重複排除 | ✔️ 標準の重複排除 | ✔️ 高度で設定可能な重複排除 |
| REST API | ✔️ フルREST API | ✔️ フルREST API |
| 認証とアクセス制御 | ✔️ ローカル認証と基本的なRBAC | ✔️ SSO(SAML/OAuth)、MFA、高度なRBAC |
| ユーザーインターフェース | ✔️ Community UI | ✔️ パフォーマンスが改善されたモダンなPro UI |
| ダッシュボードとレポート | ✔️ 基本的なダッシュボードとレポート | ✔️ 高度でカスタマイズ可能なダッシュボードと経営層向けレポート |
| 自動化とワークフロー | ❌ 含まれません | ✔️ ルールエンジンと自動化ワークフロー |
| インポートの拡張機能 | ❌ 標準インポートのみ | ✔️ バックグラウンドインポート、スマートアップロード、ユニバーサルパーサー、CLIアップロード |
| ツール連携 | ❌ 手動/API駆動 | ✔️ 主要なAppSecおよびクラウドツール向けの組み込み**アップストリームコネクタ** |
| Jira連携 | ✔️ 含まれます | ✔️ 含まれます |
| プロジェクト管理連携 | ❌ 含まれません | ✔️ **Jira**、**Azure DevOps**、**GitHub**、**GitLab**、**ServiceNow**、**Bitbucket**、**Shortcut**、**PagerDuty**、**Zendesk**、**ServiceDesk Plus**、**Freshservice**への**ダウンストリームコネクタ** |
| 検出事項の拡張機能 | ❌ 含まれません | ✔️ 自動KEV、EPSSスコアリング、ランサムウェア追跡 |
| SOCとAppSecの統合 | ❌ AppSecのみに特化 | ✔️ AppSecとSOCの検出事項を統合 |
| AIと次世代機能 | ❌ 含まれません | ✔️ AI支援ワークフロー、レポート、MCPサポート |
| サポート | コミュニティサポート(GitHub、Slack、フォーラム) | SLA付きの商用サポート |
| ホスティングオプション | セルフホスト | セルフホストまたはクラウドホスト |
