**DefectDojo Open-Source** é uma plataforma de gerenciamento de vulnerabilidades poderosa e gratuita, com importação essencial, deduplicação, painéis básicos, acesso à API e relatórios essenciais — ideal para equipes menores ou para quem deseja hospedar e estender a ferramenta usando recursos da comunidade.

**DefectDojo Pro** constrói sobre essa base com recursos voltados para empresas, como painéis e relatórios avançados, automação e scripting via mecanismo de regras (rules engine), conectores para diversas ferramentas de segurança, fluxos de importação otimizados, suporte unificado para SOC e AppSec, UI/UX aprimorada, integração com IA, segurança reforçada (SSO/MFA) e opções de suporte premium.

| Feature / Capability | DefectDojo Open-Source | DefectDojo Pro |
|---------------------|------------------------|----------------|
| Gerenciamento essencial de vulnerabilidades | ✔️ Importe, rastreie e gerencie achados de mais de 500 ferramentas de segurança | ✔️ Tudo do open-source, otimizado para escala |
| Deduplicação de achados | ✔️ Deduplicação padrão | ✔️ Deduplicação avançada e configurável |
| API REST | ✔️ API REST completa | ✔️ API REST completa |
| Autenticação e controle de acesso | ✔️ Autenticação local e RBAC básico | ✔️ SSO (SAML/OAuth), MFA, RBAC avançado |
| Interface do usuário | ✔️ UI da Community | ✔️ UI moderna do Pro com melhorias de performance |
| Painéis e relatórios | ✔️ Painéis e relatórios básicos | ✔️ Painéis avançados e personalizáveis, e relatórios executivos |
| Automação e fluxos de trabalho | ❌ Não incluído | ✔️ Rules Engine e fluxos de trabalho automatizados |
| Melhorias de importação | ❌ Apenas importações padrão | ✔️ Importações em segundo plano, Smart Upload, Universal Parser, uploads via CLI |
| Integrações de ferramentas | ❌ Manual/via API | ✔️ **Upstream Connectors** integrados para ferramentas populares de AppSec e nuvem |
| Integração com Jira | ✔️ Incluído | ✔️ Incluído |
| Integrações de gerenciamento de projetos | ❌ Não incluído | ✔️ **Downstream Connectors** para **Jira**, **Azure DevOps**, **GitHub**, **GitLab**, **ServiceNow**, **Bitbucket**, **Shortcut**, **PagerDuty**, **Zendesk**, **ServiceDesk Plus** e **Freshservice** |
| Melhorias de achados | ❌ Não incluído | ✔️ Pontuação automática de KEV, EPSS e rastreamento de Ransomware |
| Unificação de SOC e AppSec | ❌ Focado somente em AppSec | ✔️ Achados unificados de AppSec e SOC |
| Recursos de IA e de próxima geração | ❌ Não incluído | ✔️ Fluxos de trabalho assistidos por IA, relatórios e suporte a MCP |
| Suporte | Suporte da comunidade (GitHub, Slack, fóruns) | Suporte comercial com SLAs |
| Opções de hospedagem | Self-hosted | Self-hosted ou hospedado na nuvem |
