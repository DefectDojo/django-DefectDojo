DefectDojo Pro answers to a small set of keyboard shortcuts. Press **?** on any page to open the **Keyboard Shortcuts** sheet, which lists the keys the current page answers to, followed by the keys of areas that are not on the page (under **On Other Pages**). Press **?** again, or **Esc**, to close it.

Shortcuts never fire while you type in a field: a search box, a form field, a dropdown, or the markdown editor. Typing **?** or **j** in a field types the character. They also stay quiet while a dialog is open, so a key never acts on the page behind the dialog. **Cmd+K** is the one exception: it opens the command palette from anywhere, including from a field.

## Everywhere

| Key | Action |
| --- | --- |
| **Cmd+K** / **Ctrl+K** | Open the command palette (see [Global Search](/navigation/pro__global_search/)) |
| **Cmd+B** / **Ctrl+B** | Show or hide the sidebar (on screens wide enough to show it) |
| **?** | Show the Keyboard Shortcuts sheet |

## Lists

Every table of records (All Findings, Assets, Engagements, Tests and the rest) answers to the same keys. A ring marks the current row; moving the mouse over a row moves the ring there too.

| Key | Action |
| --- | --- |
| **j** | Move the ring to the next row. Past the last row, it turns to the next page |
| **k** | Move the ring to the previous row. Before the first row, it turns to the previous page |
| **Enter** | Open the row's page |
| **Cmd+Enter** / **Ctrl+Enter** | Open the row's page in a new browser tab |
| **x** | Select or clear the row's checkbox, the same as clicking it, so the bulk actions appear |
| **Esc** | Clear the ring, then, on a second press, clear the selection |

**Enter** opens a row on lists whose rows have their own page, such as All Findings. **x** works on lists that show a selection checkbox. When a page shows more than one list, the keys act on the list the mouse was last over.
