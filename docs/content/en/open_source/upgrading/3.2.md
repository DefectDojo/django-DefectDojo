3.2.x deprecates the API-based (pull) parsers and the Tool Type / Tool Configuration feature (scheduled for removal in 3.6.0) and the `django-dbbackup` integration, and adds the vulnerability-id type and multiple-CWE migrations. See the full [Upgrading to DefectDojo Version 3.2.x](../../../../releases/os_upgrading/3.2/) notes and the [Release Notes](https://github.com/DefectDojo/django-DefectDojo/releases/tag/3.2.0).
