Si votre équipe a besoin d’une installation DefectDojo sur site, merci de contacter notre équipe commerciale par e-mail → . Ce processus de configuration d’essai ne s’applique qu’aux utilisateurs de DefectDojo Cloud.

Tous les forfaits DefectDojo incluent un essai gratuit de 2 semaines, que vous pouvez utiliser pour évaluer notre logiciel. Les instances d’essai DefectDojo sont complètes et peuvent être immédiatement converties en instances payantes par notre équipe ; inutile de tout reconfigurer ou de retélécharger vos données lorsque votre période d’essai se termine.

À la fin de ce processus, vous serez mis en relation avec notre équipe commerciale, qui vous contactera pour recueillir vos informations de facturation et autoriser l’instance d’essai de votre entreprise.

Demander votre essai

Pour vous inscrire à un essai, vous devez créer un compte sur notre Portail Cloud, puis cliquer sur l’option de menu New Subscription dans la barre latérale.

Étape 1 : Bienvenue#

Cliquez sur Continue pour commencer à configurer votre instance.

Étape 2 : Saisissez les informations de votre entreprise & créez votre domaine#

Saisissez le Name de votre entreprise et le Server Label que vous souhaitez utiliser avec DefectDojo. Un domaine personnalisé sera alors créé pour votre instance DefectDojo sur nos serveurs.

Normalement, DefectDojo nomme votre domaine en fonction du nom de votre entreprise, mais si vous sélectionnez « Use Server Label in Domain », DefectDojo nommera à la place votre domaine en fonction du Server Label choisi. Cette approche peut être préférable si vous prévoyez d’utiliser plusieurs instances DefectDojo (par exemple, une instance de Production et une instance de Test). Merci de contacter notre équipe commerciale → si vous avez besoin de plusieurs instances.

Étape 3 : Sélectionnez un emplacement de serveur#

Sélectionnez un emplacement de serveur dans le menu déroulant. Nous recommandons de choisir un serveur géographiquement le plus proche possible de l’équipe principale de DefectDojo afin de réduire la latence du serveur.

Étape 4 : Configurez vos règles de pare-feu#

Saisissez les plages d’adresses IP, le masque de sous-réseau et les libellés que vous souhaitez autoriser à accéder à DefectDojo. Des adresses IP et règles supplémentaires peuvent être ajoutées ou modifiées par votre équipe une fois votre instance en service.

Si vous souhaitez utiliser des services externes avec DefectDojo (par exemple, GitHub ou JIRA), cochez les cases correspondantes sous Select External Services.

Étape 5 : Confirmez votre type de forfait et la fréquence de facturation#

Avant de finaliser le processus, veuillez confirmer le forfait que vous souhaitez utiliser ainsi que votre fréquence de facturation (mensuelle ou annuelle).

Étape 6 : Vérifiez et soumettez votre demande#

Nous vous inviterons à relire votre demande une dernière fois. Une fois soumise, seules les règles de pare-feu pourront être modifiées par votre équipe sans l’aide du support. Pour contacter le support, merci d’envoyer un e-mail à ou de suivre les instructions de cet article.

Après avoir consulté et accepté le contrat de licence et de support de DefectDojo, vous pouvez cliquer sur Checkout With Stripe ou Contact Sales.

  • Checkout With Stripe vous redirige vers une page Stripe où vous pouvez saisir vos informations de facturation.
  • Si vous ne souhaitez pas saisir vos informations de facturation pour le moment, vous pouvez cliquer sur Contact Sales, et notre équipe commerciale vous recontactera pour finaliser votre abonnement d’essai.

Une fois votre essai approuvé

Notre équipe support vous enverra un e-mail de bienvenue contenant des liens et un mot de passe initial pour accéder à votre instance DefectDojo. Vous pouvez toujours contacter pour obtenir de l’aide sur DefectDojo Pro une fois votre essai commencé.
