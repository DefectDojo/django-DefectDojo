# Code of Conduct

DefectDojo is an [OWASP Flagship project](https://owasp.org/www-project-defectdojo/). Everyone who takes part in the project, in this repository, GitHub Discussions, the community Slack, or at events, agrees to follow the [OWASP Code of Conduct](https://policy.owasp.org/operational/code-of-conduct).

In short: treat people with respect, assume good intent, keep criticism about the work and not the person, and do not harass or discriminate against anyone.

## Reporting a problem

If someone's behavior in a DefectDojo space makes you uncomfortable or breaks the Code of Conduct, contact the project leaders privately:

* [Aaron Weaver](mailto:aaron.weaver@owasp.org)
* [Matt Tesauro](mailto:matt.tesauro@owasp.org)
* [Greg Anderson](mailto:greg.anderson@owasp.org)

Reports are kept confidential. If a report involves one of the project leaders, contact the others, or use the reporting routes in the OWASP Code of Conduct.

Maintainers may edit or remove comments, issues, and pull requests that break the Code of Conduct, and may block people who repeatedly do so.

Security vulnerabilities are not conduct issues. Please report them as described in [SECURITY.md](SECURITY.md).
